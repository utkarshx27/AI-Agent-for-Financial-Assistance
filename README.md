# AI-Agent-for-Financial-Assistance
![PySpark Logo](https://cdn.prod.website-files.com/637e5037f3ef83b76dcfc8f9/66a050949c80c1143a80a514_aiagents.webp)

AI Agent for Financial Assistance is a sophisticated chatbot designed to support you in making informed financial decisions. Leveraging state-of-the-art technologies, it provides insights, analysis, and recommendations tailored to your financial queries
Features:
- Stock Analysis: Get insights into which stocks to buy and their future predictions.
- Stock Comparisons: Compare equities like Tesla and Nvidia to determine which is a better investment.
- Analyst Recommendations: Access expert opinions on stocks, such as Apple, to guide your decisions.
- Growth Potential: Discover the best equities to invest in based on their future growth potential.
- Custom Queries: Ask personalized financial questions and receive detailed, AI-driven responses.
## Description  

**Financial AI Agent** is a project designed to assist users in making informed financial decisions using AI-powered insights. It integrates advanced natural language models and financial tools to provide accurate and actionable data. The agent operates with the following key functionalities:  

### How It Works  

1. **Web Search Agent**:  
   - Powered by the Groq model (`llama-3.3-70b-versatile`) and the DuckDuckGo tool.  
   - Capable of retrieving relevant web-based information with cited sources for transparency and accuracy.  

2. **Financial Agent**:  
   - Utilizes the Groq model with integrated YFinance tools to fetch and analyze financial data.  
   - Provides insights such as:  
     - Stock prices and fundamentals.  
     - Analyst recommendations.  
     - Historical prices and technical indicators.  
     - Company news and information.  
   - Displays data in well-structured tables for easy interpretation.  

3. **Playground Environment**:  
   - Powered by the Phi API and Playground framework.  
   - Enables a user-friendly interface to interact with the agents seamlessly.  

### Key Features  
- Fetch live financial data and recommendations.  
- Compare stocks, analyze trends, and explore historical performance.  
- Transparent web-based information sourcing.  
- Easily extendable and customizable for additional use cases.  

The application serves as a robust tool for financial analysis, making it suitable for traders, investors, and researchers.
